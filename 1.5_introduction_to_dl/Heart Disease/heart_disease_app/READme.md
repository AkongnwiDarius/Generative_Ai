# Heart Disease Prediction Using Artificial Neural Network 
## 📽️project Overview 
This project focuses on developing an Artificial Neural Network (ANN) model for predciting the presence or absence of heart disease based on relevant pateint health information

## 🧠Model
The project uses an ANN for binary classification
The model predicts two possible cases:
- No heart disease 
- heart disease 
The model was trained using a training dataset and evaluated using a seperate test dataset 
The model was evaluated using:
- Accuracy
- Precision
- Recall
- F1 score 
- Confusion Matrix
- ROC Curve
- ROC-AUC Curve
This model achieved approximately 98.8% test accuracy and an ROC-AUC of approximately 0.999 on the evaluated dataset

## 📈Training Perfomance 
The model's training history was monitored using 
- Traing and Validation loss
- Training and Validation accuracy
- Training and Validation AUC
These metrics were visualized across the training epochs to observe h the model learned over time 

## 📊Confusion Matrix 
The test reults produce the following values:
- Predicted no heart disease: 3165
- Predicted heart disease: 2741
- Actual No heart disease: 40
- Actual heart disease: 33
These results indicate that the model correctly classified majority of the samples in the test dataset
